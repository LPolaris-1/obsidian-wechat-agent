# G0 验收标准

- [ ] 项目目录和核心文档齐全。
- [ ] `.gitignore` 忽略凭据、运行态和依赖目录。
- [ ] `.env.example` 只含空值变量名。
- [ ] OpenClaw 配置为 example，未包含真实 endpoint token 或登录态。
- [ ] Skill、Policy、测试和脚本均明确标注为 G0 占位。
- [ ] `npm install`（或等价无依赖安装）完成。
- [ ] `npm test`、`npm run typecheck`、`npm run lint` 通过。
- [ ] 未连接服务器、微信、DeepSeek 或 FNS，未执行部署。
